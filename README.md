# Autonomous Trash Can Companion

A browser-based fleet monitoring dashboard for Tanauan City College, built with HTML, CSS, and JavaScript.

## Features

- Monitor five simulated smart trash cans.
- View fill levels, battery levels, and fleet status.
- Select devices and inspect Canvas-based trend charts.
- Review event history and alerts.
- Adjust fill and battery levels, pause the simulation, or reset a unit.

## Run locally

Open `index.html` in a browser, or serve this folder with the VS Code Live Server extension.

## Files

- `index.html` — dashboard layout
- `styles.css` — dashboard styling
- `dashboard.js` — simulated telemetry, charts, and controls
- `tcc-logo.svg` — fallback college logo

This project uses simulated telemetry; it is not connected to live trash-can hardware.
